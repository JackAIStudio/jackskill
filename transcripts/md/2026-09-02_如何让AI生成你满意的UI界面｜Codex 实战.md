## 🎙️ 口播精修逐字稿全文

今天跟你们分享一下我们如何在 Code X 中去微调我们的 UI 你们看啊，我现在开发的这个键盘应用，它就会有个问题啊。我这一组按键，我想精确地跟 AI 描述说到底应该放在哪个位置就很难。这时候我就想起来，哎，我们其实是可以跟 AI 说，让它帮我们做一个 html 页面，然后让我们自己去调整 UI 到我们自己满意的位置。你们看这个 CodeX 就很好啊，它直接就允许我们在这个绘画中这样子拖动。把这个按钮拖动到我们想要的地方。那其他 UI 也是这样，比如说你们要调整 UI 的时候，直接让它帮你们生成这个东西，然后你们自己去把你们想要的 UI 给调整好，然后这边直接点击采用这个位置。然后呢它就直接把我们想要的 UI 的位置以这个提示词的方式来展现出来，这就很方便啊，你们看。然后采用了之后呢，其实我还加了一些，就是说因为每个手机尺寸不一样，所以要这个位置也是相对而言，我就提醒了他一下，然后他就开始改，然后就改好了。所以说现在 CodeX 改这种 UI 也很方便，你们看。直接就让 AI 生成这种 HTML 然后我们就这边按自己的意愿去调整它的相对位置，这样出来的 UI 就会准确非常多。
