## 逐字稿

今天就跟大家分享一下我是如何制作视频封面的，马上进入实战！

首先我们要跟 Agent 说一下我们自己大致希望这个视频封面是长什么样子的，我们还可以把我们想要参考的封面的链接发给 Agent。我这里也会直接跟 Agent 说我们想要做的这个视频的主题究竟适不适合这种封面。这里 Agent 就说了他的想法，哪些是可以借鉴的，哪些是不能模仿的。

这里有一点非常重要：我们在跟 Agent 沟通了几轮之后，就应该让他先出一个大致的图片。我们不能一直跟 Agent 去沟通，沟通到最后再让 Agent 作图。我们先让 Agent 根据他了解到的先画一张图片，这样我们就知道我们不想要什么、想要什么了。

像现在 Agent 就帮我出了这张图，我就知道这个图有很多的问题，比如说有非常多的元素重合，我还跟 Agent 说我希望整个图元素简单一些。

这里又有一个问题：我们在生成图片的时候要考虑到物理规律。我举个例子，像这个达芬奇的 logo 的外框是五彩的，那它散发出来的光不应该只有一个蓝光，而也应该是五彩缤纷的。所以我这边就跟 Agent 说，这张图片违背了物理规律，让它去改一下。

在经过了几轮微调之后，我就得到了我想要的符合物理规律的竖屏封面。

除了竖屏，我们还要有横屏 4:3 的。像这种竖屏转横屏，基本上一两轮就能改得通，因为我们的提示词不会经过太大的变化，保持图中的元素不变，只不过去把它们的布局、一些元素的相对大小去改成适配横屏就可以了。

那横屏 16:9 其实是同样的道理。我们有了横屏 4:3 之后，我们可以再让 Agent 去修改提示词去适配更宽的封面图。

最后我们实际上就能得到竖屏封面图、横屏 4:3、横屏 16:9，这样三个适配大多数视频平台的视频封面。
