# 视频口播逐字稿 (2023—至今，持续更新)

这里收录了我从 2023 年至今公开发布的全部视频口播文稿。这里面有折腾 AI 工具和独立开发的心得、做自媒体过程中的卡壳与反思、我的生活经历以及对一些事情的真实看法。

想了解我对某个具体话题（比如克服镜头恐惧、自媒体选题、工具用法）聊过什么，可以直接翻看对应的文章；在 Agent 中使用 `/jack` 时，Agent 也会参考这些真实的上下文来回应你的困惑。

---

## 文稿在哪

全部文稿都在 [`md/`](md/) 目录下，一期一个 Markdown 文件，文件名格式 `YYYY-MM-DD_标题.md`，日期就是这一期的发布日。

每篇的结构是固定的：

````markdown
# 视频标题

- **视频原片**：[B站](https://www.bilibili.com/video/BV...) · [抖音](https://www.douyin.com/video/...)（没有的平台不写）
- **发布日期**：YYYY-MM-DD
- **视频时长**：MM:SS (XX 秒)

---

## 逐字稿

（口播正文）
````

部分早期生活记录因平台定位调整已设为私密、或暂无外部公开链接，但口播文稿在此完整保留。

## 怎么找

- **按主题找**：直接搜 `md/` 里的正文，或者用 GitHub 的仓库内搜索。
- **按数据找**：四个平台的播放、点赞、收藏这些指标在 [`data/videos.jsonl`](../data/videos.jsonl)，每期的 `transcript` 字段指回这里的对应文稿。
- **在线看**：数据站把全部期数、四个平台的指标和逐字稿正文放在一个页面里，能搜、能排序：<https://jackaistudio.github.io/jackskill/>
- **在 Agent 里用**：装了 `/jack` 之后，它会直接检索这个目录，带着这些原话回应你的困惑。

这里没有手写索引表：它跟数据站是同一件事，站点能搜能排序、还跟着数据自动更新，手写的那份只会滞后。

## 给自动化抓取

- **正文真源**：`transcripts/md/*.md`，就是本目录
- **指标真源**：`data/videos.jsonl`，一行一期
- **单文件全集**（指标加逐字稿正文，构建产物）：<https://jackaistudio.github.io/jackskill/data/videos.json>
