# 003｜自媒体四平台发布草稿适配

## 用户要完成的事
将一份原始文案、视频逐字稿或内容纪要，一键转化适配为小红书、抖音、哔哩哔哩（B站）、微信视频号四大平台的专属发布草稿（标题、正文排版、标签）。

## 需要的输入
- 视频完整逐字稿、核心文案或内容要点；
- （可选）目标受众偏好。

## 执行步骤
1. **平台规则自适应映射**：
   - **小红书**：标题严格控制在 20 字以内（包含表情符），正文采用清单体、空行呼吸感、大量 Emoji 点缀，结尾引导互动（如“赶紧码住/评论区领”），带 3~5 个精准热门标签；
   - **抖音**：标题 30 字以内，文风口语化、接地气、强调痛点与反差，带话题 `#tag` 与 `@提醒`；
   - **B站**：标题兼具专业度与趣味性（技术向/极客向/干货向），正文包含详细时间戳索引、资源链接指引、投币点赞号召；
   - **视频号**：文风稳重克制，强调商业、效率或认知价值，避免花哨符号，带标准合集标签。
2. **违禁词与限流排查**：
   - 自动过滤和替换“最、第一、绝对、秒杀”等平台敏感与审核拦截词汇。

## 交付结果
分别输出 4 份格式完备、直接复制即可发布的 Markdown 卡片：
- **【小红书发布草稿】**（吸睛短标题 + Emoji 清单正文 + 话题）
- **【抖音发布草稿】**（悬念标题 + 紧凑文案 + 话题）
- **【B站发布草稿】**（干货标题 + 详细简介 + 资源引导）
- **【视频号发布草稿】**（商务/实用标题 + 凝练摘要）
