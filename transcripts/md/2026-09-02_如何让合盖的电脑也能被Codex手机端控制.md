## 逐字稿

今天给大家讲一下我们怎么让 Mac 以及 Windows 在合盖状态下也可以使用 Code X 来远程操控我们的电脑。首先第一步啊，你们在 Mac 或者 Windows 上都要点击这个手机连接的这个设置，去把这个设置设置一下。设置完了之后呢，先说 Mac 好吧。设置完了之后，我们点击这个设置到通用里面，点击这个登录与扩展，然后把我们的这个 Code X 这个 APP 给它加进来。这一步的作用就是让这个 Code X 可以在 Mac 中自动启动。但是这样子还不行，你们还要去下载一个这个软件， Amphetamine 它是帮助你们这个电脑在合盖的状态下也能保持系统运转的。你们打开之后就可以在顶部看到有一个这样的小的开关，你们点一下，点击这个开启新会话无限期就可以了。就说明这个系统已经开始一直运作了，就算你们合盖也能运作。安非他命还有个注意事项，允许显示器睡眠，这是对的，这样子我们在合盖的时候可以减减少显示器的这个功耗。还有一点需要注意，这个是可以勾选的，因为我们合盖的时候是用不上显示器的，它是可以睡眠的，但是这个就不能勾选。如果说我们想要合盖的状态下，系统仍能正常运行的话，勾选了这个，那系统将在一段时间之后直接自动进入休眠状态，那是不行的。这时候你们就可以直接在你们的手机上，即使合盖也能去操控你们的 Mac 了。再说一下我们怎么使用 CodeX 移动版来来控制合盖后的 Windows 电脑。首先也是同样的，我们要点击这个 Code X 移动版的这个按钮，先把这个设置给它连接上。那 Windows 版本的 Code X 桌面端是没有像 Mac 这样子有一个专门的界面，是让我们自己去把它加入到开机自启选项的。这时候我们可以直接就在 Code X 桌面端中让这个 CodeX 来帮我们配置这个开机自启。你看我直接就发这个提示词，说让它配置一下，然后它就帮我配置好了。我们在 Windows 的设置的系统选项的电源和电池中，我们还要把这个屏幕睡眠和休眠超时都改成从不啊。然后这底下有个盖子，电源和睡眠按钮。把这个盖上盖子将使用我的电脑，以及盖上盖子将使用我的电脑，这两个都改成不执行任何操作。这样子的话，你就算不接通电源，合上盖子，这个电脑还是不会休眠。这里有一点你们需要注意的，就是即使我们合盖了，如果系统不休眠的话，它消耗的电量也是比较大的。我就放了3个小时吧，我这个 Mac 电脑就已经去了百分之将近40的电了。然后你们看我这个 Windows 电脑也一样的，而且更恐怖，我放了3个小时，它直接60%的电就没了。所以说，如果说你们既想不插电，又要合盖使用的话，其实嗯可能要多配一个大功率的充电宝才行。
