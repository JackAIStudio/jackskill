## 逐字稿

我把自己在这四个平台上的所有自媒体数据，以及视频对应的逐字稿，都已经公开了。

你们让 Agent 去安装这个 Skill 之后，直接在聊天框中输入斜杠 Jack 命令，就可以获得所有的数据了。这个数据一共有 400 多行，一行就对应着一个视频，都可以让 Agent 帮你们去看。视频的标题以及视频的点赞、播放量，每一个视频都有对应的这个逐字稿。在右边你们可以直接去指定的平台去看。

如果说你们真的要做自媒体录视频，但是害怕镜头，我也出过一期视频去讲我是怎么克服这个问题的。你们还可以直接问 Jack 有哪些视频是被平台限流了。那所谓限流就是 0 播放嘛，甚至只有十几个播放，这些都能体现在我的数据中。你们可以挑选一些播放量高的，然后去看一下他这个逐字稿是怎么写的，说不定会对你们写文案有帮助。

我今天就问了 Jack 也就是我自己。我说我记得我之前做过哪个视频，但是我忘记什么时候做的了，让他帮我找出来。然后他就一股脑直接就找出来了，还把对应的这个原文都打印出来了。

我今天在让 Agent 帮我整理视频数据的时候，发现 2025 年发布的视频更少，累计播放量反而更高了。我自己也很奇怪，我就问 Agent 我说为什么呢？他直接就帮我分析出来了。25 年看似哦，播放量很高，但实际上就是有两期爆款，而且这两期爆款实际上并不能给我带来什么转化。我去年做的是那种比较泛的内容，你们看啥都有做，科技数码，甚至什么模特 vlog 甚至去探店。在 2026 年我做的事情就比较垂直了，就跟 AI 跟独立开发，跟大家的生产力有挂钩的。你们还可以看到总收藏啊、总分享啊，都是这种暴涨的。虽然说播放量降低了，但是其他数据都明显有成倍的提升。包括他还帮我分析出了整个流量的结构变化。像 25 年播放量都在抖音上，而且抖音除了那些爆款，其他的流量都没有。26 年其实基本上都是 1:1:1 了。

其实你们很多时候也不一定是问一些关于自媒体相关的问题。你们甚至还可以问我，比如说，哎，Jack，西安有什么好吃的？广西有什么好吃的？那我都能回答你，因为我这些都做了视频。那你如果说哈尔滨有什么好吃的，那我就真不知道了，因为我也没有去过，我也没做过视频。

发一个新的视频，这个 Jack skill 就会更新一轮。你们看昨天发布的视频，我立马就已经更新上了。我这个 skill 更新也很简单，你们只需要用大白话让 Agent 帮你们更新就好。

我是 Jack，希望这期视频以及这个 skill 都能给到你帮助。我们下个视频见，拜拜。
