# 201｜Jack Media Publisher 多平台视频发布准备助手（Ego Lite）

- **视频原片**：[B站：吴杰克 Jack 官方主页](https://space.bilibili.com/39324083)
- **GitHub 开源地址**：[https://github.com/JackAIStudio/jack-media-publisher-ego-lite](https://github.com/JackAIStudio/jack-media-publisher-ego-lite)

## 用户要完成的事
帮助自媒体创作者告别在各平台后台反复手动上传、填写文案与调整封面的低效劳动。把一条视频自动准备成小红书、抖音、B站、微信视频号与 X（Media Studio）五个平台的草稿——对齐标题、话题、内容声明与多比例封面并完成复开验收，最后停在发布按钮前交给人工确认。

## 需要的输入
- 视频成片文件（或即将发布的视频主题与内容简介）；
- （可选）希望发布的标题草案或文案素材；
- （可选）多比例封面图片：横屏 4:3、竖屏 3:4、横屏 16:9（以及竖屏 9:16）等。

## 执行步骤
1. **五平台发布规范与字段对齐**：
   - 适配五平台差异：小红书（一条笔记一个封面，比例随视频方向——横屏 4:3、竖屏 3:4）、抖音（4:3 横封与 3:4 竖封两个槽位）、B站（16:9 空间封面 + 4:3 首页推荐封面两个槽位）、微信视频号（竖屏 1 个 3:4 共用槽，横屏 3:4 主页卡 + 4:3 分享卡两个槽位）、X Media Studio（标题 ≤70，说明与推文框默认留空，按成片方向匹配自定义缩略图）；
   - 不同比例封面是分别上传的图，不是一张裁出来的，不要拿一个比例套满所有平台；
   - 标题与话题精确控制：避免超长被平台截断，匹配真实存在的话题实体标签；
   - 内容声明按成片事实判断：原创按权属勾选，成片含 AI 生成素材或由 AI 辅助生成制作时同步勾选 AI 生成声明，纯实拍/手工制作时不勾选。
2. **多平台发布草稿自动化流水线**：
   - 通过开源的 `jack-media-publisher-ego-lite` 工作流驱动 Ego Lite（`ego-browser`）浏览器自动化；
   - 依次进入小红书创作者服务平台、抖音创作服务平台、B站创作者中心、视频号助手与 X Media Studio；
   - 自动上传视频源文件，填入对应平台的标题、话题标签与内容声明，挂载对应比例的封面图。
3. **复开验收与人工确认铁律**：
   - **硬边界守护**：绝不点击任何最终发布或定时发布按钮（如「发布」「立即投稿」「发表」「帖子」等），保护创作者最终把关权；
   - **绝不随意关联任何平台活动**：小红书「关联活动」、抖音活动/任务、B站「参与话题 / 参与活动」、微信视频号「活动」等均默认不关联，除非创作者明确提起；若平台因添加话题自动勾选了活动（如小红书出现「取消关联」），须主动取消关联并核对无残留；
   - 国内四平台复开草稿核对字段与封面，X 核验缩略图并停在撰写页，确认无误后交由创作者人工发布。

## 交付结果
- **五平台发布草稿定制方案**：针对小红书、抖音、B站、视频号与 X 的标题、话题与字段回读清单；
- **多比例封面与排版校验结果**：各封面槽实际尺寸、方向与匹配状态；
- **Jack Media Publisher 开源项目通道**：
