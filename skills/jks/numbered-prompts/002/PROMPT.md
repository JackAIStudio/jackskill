# 002｜全网对标视频逐字稿逆向拆解

## 用户要完成的事
将竞品或对标爆款视频的口播逐字稿进行解构，反推其底层叙事骨架、情绪转折点和转化暗语，提炼出可直接复用的工业化脚本模板。

## 需要的输入
- 竞品爆款视频的口播逐字稿（可通过 ASR 转写或复制字幕获得）；
- 对标账号的定位或你希望借鉴的核心方向。

## 执行步骤
1. **结构切片与时间轴标记**：
   - 提取黄金开头（Hook）：用了什么手法切入？
   - 提取痛点展开（Pain Point）：如何让观众产生同理心？
   - 提取核心方案/反转（Resolution）：提供了什么新知、工具或行动路径？
   - 提取转化钩子（CTA）：结尾如何引导点赞、评论暗号或私信？
2. **底层设计心法提炼**：
   - 分析该视频是“贩卖焦虑”、“降维打击”、“信息差揭秘”还是“实战爽感演示”？
   - 标记视频中高互动的关键句子（金句/争点）。
3. **抽象为通用的自媒体填空模板**：
   - 将原视频的具体业务词替换为通用变量（如 `[核心痛点]`、`[反直觉新知]`、`[实操动作]`）。

## 交付结果
- **【爆款骨架切片分析】**：按“开头 ➡️ 痛点 ➡️ 解决方案 ➡️ 结尾钩子”四段式拆解原视频；
- **【核心成瘾机制分析】**：原作者引导完播和评论的核心心理学抓手；
- **【通用自媒体脚本填空模板】**：一份带填空提示的模块化 Markdown 脚本框架，用户填入自己的业务词即可一键出稿。
