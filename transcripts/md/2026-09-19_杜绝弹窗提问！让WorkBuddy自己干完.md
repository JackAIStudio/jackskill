## 🎙️ 口播精修逐字稿全文

有时候你在 WorkBuddy 中给 Agent 指定一个指令，他任务干到一半突然向你提问。这个时候就很闹心了。
我们理想中的状态是我们给了 Agent 允许完全访问权限，那它就应该吭哧吭哧哧的全部干完。
我们既然都用了 WorkBuddy 这种 AI 产品，那也就不会说下达了一个指令之后，搁这干等着，肯定要么去做别的事情，要么就直接干脆离开电脑桌。
可是事实上是他依然遇到一些疑惑的点，直接就给你几个选项让你选择，那我觉得这就很扯了。
那就变成不是我们给 Agent 下达指令了，而是 Agent 给我们下达指令了。
接下来就说怎么样最大程度地给 Agent 权限。
为了给 Agent 最大的权限，我们不仅要开放允许完全访问，还要点击左下角前往设置，点击个性化。
这里有个自定义指令，你们可以看一下我说的，我就是跟 Agent 说，让他不要中途停下来问我，也不要给我选项，除非遇到那种非常严重的不可逆操作，或者说跟我们的隐私相关的时候，才允许提问。
我们还要在 Workflow 的长期记忆中加上这样一条类似的命令，
让他能自主执行
他真的遇到了有什么问题，他就会直接结束这个任务，而不是阻塞这个任务。
当然你们像我这么做有个缺点，就是 Agent 本身它是有幻觉的，不可避免的有时候它会犯错。
它会不经过你的同意，即使我们这边说了不要删除一些东西，它还是会删除。会覆盖，所以说有得必有失嘛，我们给了 Agent 最大的权限，那我们也要承担相应的后果，这个大家就自行去考量。
这里是 Jack，和我一起用 WorkBuddy 提高你的工作效率吧！非常感谢你的观看，我们下个视频见，拜拜！
