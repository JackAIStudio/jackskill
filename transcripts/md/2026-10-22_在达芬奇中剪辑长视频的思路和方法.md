## 逐字稿

你们看啊，昨天我拍了 3 个小时的素材，最后我剪成成片只有两分钟。

刚开始我会让 Agent 根据我的想法，让他先剪一版，选取我想要的这个视频片段。选取完之后，我发现还是太长了，然后整个视频没有重点。所以我后面就让 Agent 直接来读取对应达芬奇的这个视频画面。让他去挑选片段的时候，要看一下对应的这个句子。

三个小时的视频素材，我们必须要压缩，有些东西不要的就丢掉。确立了我们还是要以吃饭为核心，所以前面几个小时的内容就直接一笔带过。

Agent 给了我一个新的版本之后，我发现就会好很多。又有我人物，又有这个骑行画面，然后接下来又切换到跟别人的互动，然后又切换到我自己的视角，最后再到吃饭，流程就很通畅，不会像原来那样，呃，一大半都是在骑车啊，你们看。这种骑车实际上是没什么意思的，所以说，这就是我的一个剪辑思路吧。

拍 3 个小时的素材，好处就是你可以让 Agent 去挑选。你可以跟 Agent 说你想要什么样的片段。坏处就是素材太多了，你找不到重点。很多时候你只能去呃，压缩一些视频时长，然后去把一些重点讲出来。

你们昨天看到的这个成片，实际上就是我让 Agent 帮我去粗剪之后，我自己再稍微细调一下得到的一个结果。

再说一下我是如何让 Agent 去帮我剪辑达芬奇时间线的。我用的就是我自己开发的这个达芬奇 AI 剪辑助手。它是可以直接让 Agent 能够看懂你的达芬奇时间线的，然后根据画面、文字、声音等多个维度去帮你进行智能剪辑。

你们下载好这个软件之后，直接在 Workday 或者 CodeX 或者豆包里面输入这个斜杠，Jack AI cut，然后 Agent 就会告诉你。直接输入这个，Agent 接下来就会指引你去怎么进行 AI 剪辑。文件也不大，只有几 MB。

如果说你们和我一样要剪这种长视频，甚至是纪录片的话，我非常的推荐你们去试一下，因为它真的能节省你们很多的时间啊。
