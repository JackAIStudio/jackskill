平台表现

中位播放比平均播放更能代表常态——单条爆款会把平均值拉得没法看。 互动率 = （点赞 + 收藏 + 分享 + 评论）÷ 播放，收藏率 = 收藏 ÷ 播放。

时间线

平台是逐年接入的：2023 年只有 B 站，2024 年主要是小红书，2026 年才四平台齐全。 所以按平台各画一条线，不做总量堆叠——早期总量低是因为当时没采别的平台， 不是流量低。线断掉的地方就是那个月没数据。

口径

上面每个数字怎么算出来的，都写在这里。看完这一节，页面上任何一个数你都能自己验算。

指标算式说明
播放 / 点赞 / 收藏 / 分享 / 评论 各平台相加 作品表一行的「合计」= 四个平台那一列之和；全站数字 = 所有期相加。加总的口径由 check-data.mjs 每次构建时校验，对不上就不出页面。
互动率 （点赞 + 收藏 + 分享 + 评论）÷ 播放 每 100 次播放换来多少次互动。平台之间比这个，比比播放量有意义——播放量受平台体量影响，互动率不受。
点赞率 / 收藏率 / 分享率 / 评论率 该指标 ÷ 播放 作品表末列，跟着上面选的指标切换；表头小字和图例里都写着当时那一列的算式。
中位播放 把播放量排序，取中间那个 不用平均：单条爆款能把平均拉到失去意义，中位数拉不动。

三个要知道的口径边界

看到什么什么意思
— 这一期在这个平台没有数据。两种可能：没发到这个平台，或者发了但没采到数（数据源里是五个指标全 0 的占位记录）。光标停上去会告诉你是哪一种。
「未收录原片链接」 数据源里这一期只存了创作者后台的地址，观众点进去只有登录墙，所以干脆不给链接。换成作品直链之后就会显示成「看原片」。
「平台主页」 小红书和视频号在数据源里存的是平台主页，不是某条作品——这两个平台的笔记链接受风控和 token 限制，存下来很快会失效。

五个指标全是 0 的记录不进任何统计：不算收录期数，不进中位数，也不参与排序。 这些不是「还没去后台抄」——照抖音创作者后台逐条看过，这批作品的状态是 「不适宜公开 / 减少作品推荐 / 限制自己可见 / 已删除」，平台侧根本不提供数据。 记录留着，是因为「这一期发过、但被平台限流了」本身也是这个仓库的真实状态。

数据与逐字稿的唯一真源都在本仓库： data/videos.jsonl、transcripts/md/*.md。 页面是构建产物，改数据后重跑 node scripts/build-site.mjs 即可。

给程序的入口：llms.txt（机器可读索引）、 data/videos.json（全部指标与逐字稿的单文件版本）。
