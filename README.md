# JackSkill（吴杰克 Jack 把自己开源了）

吴杰克 Jack 的个人全量开源实录：收录了他在 B 站、小红书、抖音、微信视频号的真实自媒体数据、全部视频口播逐字稿，以及日常自研的高效生产力工具。

**无需在本地翻找文件或写代码。在任意支持的 Agent 聊天框中，输入一条 `/jack` 即可全盘调用。**

支持环境：豆包、WorkBuddy、Codex、Claude Code，以及所有支持 Agent Skills 的智能体。

---

## 快速安装

在终端执行一行命令，安装到本机：

```bash
npx -y skills add JackAIStudio/jackskill -g --all
```

## 在 Agent 中唤醒（/jack 口令玩法）

安装完成后，在任意 Agent 聊天框中输入 `/jack` 即可直达：

### 1. 查真实自媒体数据与避坑（用数据说话）

不看虚假战绩，直接调取跨平台真实表现：

- `/jack 你播放量最高的视频是哪几期？讲了什么？`
- `/jack 有哪些视频被平台限流了？怎么复盘原因？`
- `/jack 技术分享内容在 B 站和小红书的表现有什么差异？`
- `/jack 哪期视频的收藏量远大于点赞量？`

### 2. 聊自媒体创作、困惑与经历（引述口播原话）

遇到瓶颈或迷茫时，检索口播逐字稿实录交流：

- `/jack 我想做自媒体录视频，但面对镜头感到害怕，该怎么调整？`
- `/jack 自媒体口播文案怎么写才自然？`
- `/jack 普通人现在做自媒体还来得及吗？`

### 3. 调自研生产力工具直接干活（输入编号即用）

围绕自媒体创作全流程打磨的工具链，涵盖商业旗舰与开源实用工具：

- `/jack 888`：**JackAICut 达芬奇 AI 剪辑助手（商业产品）** —— 让 Agent 看懂你的达芬奇时间线，根据画面、文字、声音等多个维度帮你剪辑，只要是达芬奇用户都能显著提升剪辑效率。
- `/jack 201`：**Jack Media Publisher 多平台发布（开源）** —— 一键分发视频至小红书、抖音、B 站、微信视频号，对齐标题封面并生成草稿。
- `/jack 101`：**JackVoice 极低声轻语输入（开源）** —— 在图书馆或安静办公室轻声轻语即可准确转文字，自带备忘录。
- `/jack 666`：**JackDSH 桌面 AI 工作台指南（开源）** —— 开箱即用的桌面 AI 工作台，支持手机远程控制。

常用指令：
- **查看清单**：输入 `/jack list` 获取最新技能与逐字稿概览。
- **一键更新**：对 Agent 说 **“更新 jackskill”**，自动同步最新数据、逐字稿与技能。

## 底层事实资产

`/jack` 指令之所以能精准回答上述问题，是因为其背后由本项目完整公开的三套事实资产支撑：

### 1. 自媒体跨平台互动数据 (data/videos.jsonl)

完整记录他在 B 站、小红书、抖音、微信视频号发布的真实视频数据：

- **真实不粉饰**：不只记录爆款，扑街、低播放和被平台限流的视频数据同样保留，供创作者客观参考什么样的内容真正有流量、什么样的选题容易受限。
- **数据与逐字稿双向索引**：每条数据都直接关联对应的 Markdown 逐字稿文件。在看到播放、收藏等指标的同时，能直接翻看当期视频说了什么、开头怎么抓人。
- **跨平台调性对比**：同一期视频在四个平台的分发数据同步列出，直观展示长视频与短视频平台的算法差异与受众偏好。

### 2. 视频口播逐字稿 (transcripts/md/)

收录了吴杰克发布的全部视频口播逐字稿，跟随最新视频同步更新。每一篇均为独立的 Markdown 文件，真实保留口播原话、选题切入点与文案结构。
