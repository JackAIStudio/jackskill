## 🎙️ 口播精修逐字稿全文

现在你们使用我的这个 skill，就可以做到一键把你们的视频发布在国内的主流视频平台上。

你们提前把视频封面、把最后的视频、把各个视频平台对应的文字标题和文字标签跟 Agent 说清楚。在 Agent 帮你发布视频的这个过程中，你其实可以在 Chrome 浏览器中的其他标签页去浏览网页，这并不会影响 Agent 在后台帮你继续工作。

你们不用担心使用这个 skill 会对你们的账号造成影响，最后那个发布按钮还是要你自己去点的，我们总是要检查一遍 Agent 它做的是不是正确的。

你们使用我这个一键发布 skill，需要前往 Chrome 应用商店去安装这个 BrowserSkill 的插件，它可以做到让 AI Agent 在你已经登录的 Chrome 浏览器里面工作。你们安装了扩展程序之后，需要点击详情，往下面滑，这里有一个“允许访问文件网址”，你们要把它勾上。

我前面说的这些准备工作，你们也可以不提前做，因为你们在使用我这个 skill 的过程中，Agent 发现走不通也会跟你们说的，它到时候会给你们链接，你们一一按照他的说法去做就可以了。

你们可以根据我这个 skill 再让 Agent 帮你们改进，比如说你们需要填写简介，或者说要定时发布，或者说加入一些合集，这些我自己是没需求的，你们如果有需求可以让 Agent 帮你们去加就行。包括这里有个创作声明，假如说你们的视频内容，或者说你们的视频封面是由 AI 制作的，那你们可能要勾选“这个视频内容含 AI 合成”。

我看到了一个博主 Oil，他自己开源了一个一键发布 skill，但是他发布的这个 skill 是用于 Ego Lite 这个浏览器的。所以我就在他的基础上做了一个适合 Chrome 浏览器进行一键视频发布的 skill。这里我也非常感谢这个博主，因为我在做这个 skill 的时候发现有很多坑，他都提前帮我踩过了，包括你们看这个标签要符合平台自己的标签的样子，毕竟每个视频平台它的标签的样式是不一样的，这些工作 Oil 都已经帮我踩过坑了。如果说你们跟 Oil 一样用的也是 Ego Lite，那你们就用他这个 skill；如果说你们用的是 Chrome 浏览器，那你们可以用我这个 Jack Media Publisher。

这里是 Jack，关注我获得更多 AI 干货和前沿资讯，我们下个视频见！拜拜！
