## 逐字稿

我认为 Browser Skill 在开源的浏览器控制插件中，它就是 number one。
它可以做到让 AI 操作你的浏览器，但却并不打断你的工作。
我现在在 DSH 中实操给你们看，你们就知道它有多厉害了。
我们先是使用这个 Browser Skill 然后让它打开我的 Chrome 浏览器，看一下我最近关注的博主。
最近这一周都发了什么内容？
点击发送。
它现在就打开了这个浏览器，对吧？
它不会打断你现在用的这个浏览器的标签，你知道吗？
它会新开一个窗口页。
我们就只需要在另外一个浏览器窗口做自己的事情，两者都完全不会被打扰到，这就是我觉得非常好的地方。
而且它这个 UI 你们看，设计的都很好，橙色的光你们看，他现在就是一直正在去操作。
如果你们和我一样安装了这个 Better Sidebar 它也是一个 DSH 的插件，就可以做到两个插件的联动，你们就直接可以在这个 DSH 中看到。
Agent 它实时做了什么。
就像现在对吧，我们就可以看到它正在找翠猫这个博主以前的一些帖子。
你们可以看到他在做完浏览器操作之后，原先他自己打开的那个浏览器窗口直接就被静默关闭了。
所以说，就整个体验非常的流畅。
你在自己的浏览器窗口做一些其他的工作。
而他默默地起一个新的浏览器窗口，在那边做事。
Browser Skill 在我看来就是 DSH 中必装的一个插件，它真的极大的提高了 Agent 操作浏览器的能力。
你们在左上角就可以看到这个工具是由腾讯团队开源的。
我只能说大厂就是大厂，
能力还是在线的。
安装这个 Skill 就是一句话的事。
往下滑，它这边有一个让 Agent 帮你安装，你直接点击复制一下。
发送给 Agent 就可以了。
