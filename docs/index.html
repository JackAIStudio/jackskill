平台表现

中位播放比平均播放更能代表常态——单条爆款会把平均值拉得没法看。 互动率 = （点赞 + 收藏 + 分享 + 评论）÷ 播放，收藏率 = 收藏 ÷ 播放。

时间线

平台是逐年接入的：2023 年只有 B 站，2024 年主要是小红书，2026 年才四平台齐全。 所以按平台各画一条线，不做总量堆叠——早期总量低是因为当时没采别的平台， 不是流量低。线断掉的地方就是那个月没数据。

数据与逐字稿的唯一真源都在本仓库： data/videos.jsonl、transcripts/md/*.md。 页面是构建产物，改数据后重跑 node scripts/build-site.mjs 即可。
