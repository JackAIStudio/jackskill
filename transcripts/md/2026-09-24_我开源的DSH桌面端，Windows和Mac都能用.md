## 逐字稿

我开发的这个 DSH 桌面端竟然完美适配！这是 Windows 的效果，这是 Mac 的效果。

主要我没想到这么流畅，你们知道吗？我原来都是在 Mac 上开发的，但是我今天发现在 Windows 上一下子就能跑通，DSH 在 Windows 上挺快的，没有想象中那么慢啊。我刚下过来，它这边一直会弹这个 PowerShell 的窗，到时候我再优化一下。

给你们看一下啊，我自己开发了超多的插件，数不清了，估计有十多个了吧。比较重磅的就是这个手机远程控制啊，局域网啊或者说公网都可以。

还有这个会话深层导航，就是说你可以跟 Agent 说最近聊了什么，Agent 它直接就帮你导航到对应的对话。

哦，我这个 DSH 桌面端还集成了一个浏览器控制的插件，Browser Skill，这个浏览器插件算是我认为目前开源最好用的了。

大家去我的 GitHub 就可以下载了哈，这些都是我已经都开源了。你们如果说不想下载桌面端，只想下载单独的插件，直接去这里下载就可以了。我更新了超多版本，最近都在疯狂更，一共有两个版本哈。Mac 就是你拖一下就能安装；Windows 你解压下来就可以直接打开了，都不用安装，因为我这个打的就是便携包。

大家下载下来直接填 DeepSeek 的 API Key 就可以用了。如果说你们有 Gemini 或者说 Grok 的这个订阅计划，你们也可以用它们的。后面我也会持续添加更多的功能。
