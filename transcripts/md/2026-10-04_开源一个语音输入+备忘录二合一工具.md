## 逐字稿

你们现在看到的这个东西就是我开源的一个桌面语音听写工具。

它还有顶部这个待办备忘录的功能，我只要点一下这个，它就及时把我们想要的语音听写转为备忘录了。假如说我们这个事情做完了，再点击删除就可以了。

我这个软件还有个优势，你们看，它是可以任意拖移的，我们可以把它拖移到任何地方。那有时候我们比如说挡住了，很难拖回去怎么办呢？这时候我这里就又有一个将预览胶囊移到屏幕中央的功能。

你们可以添加自己的词库，有的时候热词都没有办法去把这个 ASR 的错误纠正过来，那我们就添加替换词。

这个听写工具，它是支持超低声输入的。有的时候我们在办公室，或者说在图书馆，不能太大声的说话。给你们看看它这个效果是怎么样的。

我现在在汉庭酒店，轻轻的说话。你听得到吗？

你们看，它这边能识别出来，刚才那一句很轻的声音。我自己用的就是豆包语音的这个 API Key，因为它是轻声输入下识别效果最好的。

你们当然可以换成阿里云的，如果说你们没有这样的需求，或者说你们希望用自己本地的模型，或者说用别的 ASR 的 API，你们都可以让 agent 去把这个源码克隆下来，然后让 agent 帮你们去改。

我这个语音听写工具还有个优点，它很稳定。有时候我们可能网络不是很好，那这时候它就识别不出来，它会事先帮你把这个音频保存出来，等后面你到了一个网络稳定的环境，点击重新转写就可以了。

你们看这里有很多功能，可以选择是否添加标点，是否自动整理口语。在这里你们还可以选择使用哪一个麦克风，你们可以在这里选择听写的快捷键。

如果说你们用的是 Mac，可以直接点击这个 Release 去下载最新的这个 DMG 安装包。如果你们用的是 Windows，那你们可能需要自己编译。我之前在 Windows 上测试过，它是能打开的，但是我没有很长时间的去测试，所以说这里就不主动把那个 Windows 的 EXE 安装包打出来了。

如果说你们想了解更多我的项目，你们也可以让 agent 去安装这个 jackskill，这个 skill 它收录了我所有的开源工具、商业产品以及全部视频的口播逐字稿。
